The blind spot

Per-transaction models score accounts in isolation. Rings live between accounts.

Money-laundering cycles, bust-out fan-outs, buyer–seller collusion, device farms — coordinated abuse is individually invisible, collectively obvious. A model that looks at one row at a time never sees the pattern the group forms together.

A per-row model sees

Isolated accounts, each with unremarkable stats. Every member of the ring passes.

The graph sees

The same accounts, now connected — a dense structure no single row reveals. The ring stands out.

The system

Detection is only the first step. The rest keeps it accountable.

Nothing is auto-frozen. Every flag becomes an evidence-backed case a human signs off on, and every decision is remembered.

01

Detect

A GraphSAGE model scores every account using its connections, not just its own features.

02

Triage

Scores split into clear, auto-flag, and human-review — no account is silently blocked.

03

Investigate

An agent builds a case where every claim carries a pointer to the evidence behind it.

04

Human decides

A reviewer approves or overrides with a reason. Required by law before any fraud label.

05

Remember

Recommendation and human verdict are appended side by side — an auditable, learning ledger.

Real Elliptic graph — the honest picture

On real data the tabular model is strong, because Elliptic's features already bake in neighbour aggregates. The graph model's edge is learning that structure end-to-end instead of relying on hand-engineered features.
GraphSAGE — F10.66
RandomForest — F10.81
Why report the lower number? F1 stays ~0.66 across every decision threshold — a stable, honest ceiling set by distribution shift in the test period, not a tuning artifact. The threshold instead becomes a business dial: high-recall to catch more fraud, high-precision to spare good customers.
Accountability

Every decision is kept, in parallel, so someone is answerable for it

The model's recommendation and the human's verdict are stored as separate, append-only records. You can always tell whether the model was wrong or a human overruled a correct call — and overrides become training signal.

Grounded in real rules

Before any account can be classified as fraud, a human must sign off — the natural-justice requirement India's RBI adopted for fraud risk management. The review step isn't UX polish; it's the rule, operationalised, with the audit trail as evidence.

Where it goes next

Built to extend

Temporal graph models

Time-aware GNNs (EvolveGCN, TGN) to track fraud that shifts across periods — the real fix for the Elliptic ceiling.

Learning from the unlabelled

Semi-supervised and PU learning to use the ~77% of the graph that has no label — the realistic case in production.

Multi-relation graphs

One graph over device, bank, IP and email edges at once, so rings hiding across signals surface together.

Adversarial hardening

A red-team that evolves rings to evade the detector, then adversarial training so it holds up against adaptive fraud.
